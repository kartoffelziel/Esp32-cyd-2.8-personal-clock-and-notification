Fonts embedded in the firmware (as pre-rendered bitmaps in src/fonts_data.cpp)
==============================================================================
UI text and the default date font ... DejaVu Sans / Sans Bold (Bitstream Vera + DejaVu licence)
Arial-like clock/date font .......... Liberation Sans Bold (SIL OFL 1.1) - metric compatible with Arial
Helvetica-like clock/date font ...... TeX Gyre Heros Bold (GUST Font License) - clone of Helvetica (URW Nimbus Sans)
Calibri-like clock/date font ........ Carlito Bold (SIL OFL 1.1) - metric compatible with Calibri
JetBrains Mono, Outfit, Big Shoulders, Jura, Gloock, Poiret One, Pixelify Sans, Lora ... SIL OFL 1.1 (see *-OFL.txt)

Arial, Helvetica and Digital-7 are proprietary / personal-use-only fonts and are NOT included.
The "LED 7 doan" and "Digital-7 (nghieng)" clock styles are drawn procedurally by the firmware.
